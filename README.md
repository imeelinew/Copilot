# 面试话术库

面向前端实习面试的本地优先回答检索工具。问题和答案使用 Markdown 管理，浏览器内完成即时搜索；题库没有可靠答案时，可以调用可配置的 Agent 接口生成一次性回答。

## 开发

```bash
npm install
npm run dev
```

## 内容格式

题库位于 `content/`。每道问题对应一个 Markdown 文件，主要字段包括：

- `title`：标准问题
- `aliases`：面试官可能采用的其他问法
- `category`：所属分类
- `projects`：关联项目
- `keywords`：用于召回的关键词
- `priority`：是否优先复习

正文支持 `30 秒回答`、`标准回答`、`深入回答`、`回答要点`、`面试官可能追问` 和 `代码证据`。

## Agent fallback

前端默认向 `/api/answer` 发送请求，也可以通过环境变量设置服务地址：

```bash
VITE_AGENT_ENDPOINT=http://127.0.0.1:3000/api/answer
```

请求体：

```json
{ "question": "用户没有在题库中找到的问题" }
```

响应体：

```json
{ "answer": "一次性展示的口语回答" }
```

Agent 结果不会写回 Markdown 题库。

## 多用户题库

点击右上角头像切换用户，或输入用户名创建新用户：

- 默认用户「牛」保留 `content/` 中原有的 137 道题，并继承旧版本的收藏。
- 新用户从空题库开始，点击「导入题目」可批量选择 `.md` 文件。每个文件至少包含 frontmatter 中的 `id`、`title` 和答案正文；其余字段及正文小节沿用上面的内容格式。
- 同一用户内题目 ID 不可重复，不同用户可以使用相同 ID。遇到重复 ID、缺失必需字段或单批超过 2 MB，整批不导入。
- 用户列表、当前用户、导入题目和各自收藏保存在当前站点的浏览器 localStorage 中；刷新后恢复。切换时重置搜索、分类、选中题目和临时 Agent 回答。

这是本地用户档案功能，不提供登录鉴权、跨设备同步或隐私访问控制。清理浏览器数据会丢失本地档案和导入内容，请保留 Markdown 原文件。内置 `content/` 只属于默认用户。

Agent 请求额外携带 `userId` 和 `userName`，服务端需自行按用户关联上下文；前端不会上传用户的整份题库。切换用户时会取消尚未完成的请求。
