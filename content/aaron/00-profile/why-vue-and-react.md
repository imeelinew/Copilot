# 为什么同时学 Vue 和 React？哪个更熟？

## 核心回答

顺序是先学的 Vue 2，当时它资料多、上手快，很快就能做出完整的东西。后来学 React，一半是工作需要，一半是发现两个框架解决同一个问题的思路不一样，对比着学理解更深。所以做项目时我故意分开：Vue 3 做了移动端电商，React 做了数据可视化，Vue 2 做了工单系统，每个栈都有一个完整项目兜着。

更熟哪个的话，Vue 3 和 React 我都能独立做完项目。Vue 接触得早，踩的坑多一些；React 最近写得更多，配 TypeScript 的体验我很喜欢。

## 展开回答

留着 Vue 2 项目还有一个原因：很多公司的老系统还在 Vue 2 上，会读 Options API、知道它响应式的那些限制，是实际用得上的能力，不能因为出了 Vue 3 就当 Vue 2 不存在。入职之后如果团队有明确的技术栈，我肯定以团队的为准。框架这层我切换没什么负担，组件设计、状态管理这些东西在哪个框架里都是通的。
