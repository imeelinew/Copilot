# 路由守卫判断有 Token 就放行，算完成鉴权了吗？退出登录做了什么？

## 核心回答

不算完整鉴权。当前路由守卫只负责前端页面访问控制：登录和注册放在白名单里，其他页面如果本地没有 Token，就跳回登录页。它不能判断 Token 是否过期或伪造，也不能判断当前用户有没有权操作某个订单，真正的身份和资源权限必须由服务端验证。

退出登录目前会删除本地 Token，再跳回登录页，这能结束前端保存的登录状态，但不能直接证明服务端会话已经撤销。项目也没有统一的 401 处理和 Token 刷新流程。以后可以根据后端认证方案增加统一失效处理，并在退出时清理与用户相关的结算数据和缓存。

## 回答要点

- 当前路由守卫只负责前端页面访问控制：登录和注册放在白名单里，其他页面如果本地没有 Token，就跳回登录页。
- 它不能判断 Token 是否过期或伪造，也不能判断当前用户有没有权操作某个订单，真正的身份和资源权限必须由服务端验证。
- 退出登录目前会删除本地 Token，再跳回登录页，这能结束前端保存的登录状态，但不能直接证明服务端会话已经撤销。
- 项目也没有统一的 401 处理和 Token 刷新流程。
