# AI 限流还不是全站配额

## 核心回答

目前 AI 接口按照 IP 做分钟和小时限流，可以挡住单个运行实例中的连续请求，但计数放在内存 Map 里。Serverless 扩容后，不同实例之间看不到同一份计数，实例重启后数据也会消失；而且接口目前没有按商城用户鉴权，所以它只能算基础保护。

如果继续完善，我会把计数放到 Redis 一类的共享存储里，用原子操作实现跨实例限流，同时结合用户 ID、IP 和全站预算设置不同层级的额度。这样既能限制单个用户，也能控制整个应用的模型费用。

- 目前 AI 接口按照 IP 做分钟和小时限流，可以挡住单个运行实例中的连续请求，但计数放在内存 Map 里。
