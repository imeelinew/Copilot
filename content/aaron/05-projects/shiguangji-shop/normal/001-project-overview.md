# 项目介绍（约 1 分半到 2 分钟）

## 核心回答

拾光集是一个使用 Vue 3 开发的移动端商城项目，主要面向普通消费者。项目围绕一条完整的购物流程来设计：用户先注册登录，然后在首页或者分类页浏览商品，也可以通过关键词搜索商品；进入商品详情后可以查看价格、图片、商品介绍和评价，选择具体规格后加入购物车或者直接购买；最后再选择收货地址、确认订单，并在订单列表里查看后续状态。

项目主要分为用户、首页、分类搜索、商品详情、购物车、地址和订单几个业务模块。用户模块负责注册、登录、登录状态保存和页面访问控制；首页模块展示轮播图、公告和推荐商品；分类搜索模块支持按分类找商品、关键词搜索、热门搜索和搜索历史；商品详情模块负责商品信息、SKU 规格、收藏、评价、加购和立即购买；购物车模块支持店铺分组、勾选、全选、数量修改、删除和服务端计价；地址模块支持新增、编辑、删除、默认地址和订单临时选址；订单模块负责确认订单、提交订单、支付接口调用以及不同状态的订单列表。

在这些基础功能之外，我还给搜索联想和商品卖点接入了 AI。AI 正常时根据关键词或商品信息生成内容，接口异常时会切换到本地规则，避免页面完全没有结果。为了让项目更适合实际部署，改进版还增加了服务端 AI 代理、商城接口代理和旧图片代理：浏览器只访问本站接口，AI 的共享密钥由服务端保存，旧图片地址也统一转换成本站路径。

技术上，前端使用 Vue 3、TypeScript、JavaScript、Vant、Vue Router、Axios、Sass 和 Vite。移动端适配使用 rem 和 PostCSS；网络层统一处理接口地址、Token 和响应数据；首页使用并行请求和骨架屏改善等待体验；购物车和搜索还处理了异步请求返回顺序不一致的问题。
