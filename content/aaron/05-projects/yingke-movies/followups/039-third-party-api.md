# 直接从客户端请求第三方影视接口有什么风险？

## 核心回答

当前客户端直接请求第三方移动端地址，主要风险是合法域名限制、接口变更、限流、服务不可用和返回结构不可控。如果第三方接口需要密钥，客户端直连还会暴露凭证。正式业务可以通过自己的后端代理第三方请求，统一做鉴权、缓存、限流、数据清洗和错误兜底。不过当前项目没有后端代理代码，所以我只能说客户端调用链路已经存在，不能说接口长期可用、已经获得生产授权或线上稳定运行。
