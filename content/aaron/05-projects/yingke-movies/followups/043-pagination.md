# 怎样验证分页没有重复或遗漏？

## 核心回答

我会先在 Network 中确认 `start` 是否按 0、8、16 递增，再记录每一页返回的影片 ID，核对追加后的列表有没有重复。然后测试快速连续触底、最后一页不足 8 条、接口返回空数组、请求失败重试，以及进入详情后再返回列表。页面最终数量应该和服务端 `total` 对得上，而且同一个 ID 不应该因为生命周期重入重复出现。当前代码没有请求锁和去重，所以这些场景需要重点验证，不能预先说已经通过。

## 回答要点

- 我会先在 Network 中确认 start 是否按 0、8、16 递增，再记录每一页返回的影片 ID，核对追加后的列表有没有重复。
- 然后测试快速连续触底、最后一页不足 8 条、接口返回空数组、请求失败重试，以及进入详情后再返回列表。
- 页面最终数量应该和服务端 total 对得上，而且同一个 ID 不应该因为生命周期重入重复出现。
- 当前代码没有请求锁和去重，所以这些场景需要重点验证，不能预先说已经通过。
