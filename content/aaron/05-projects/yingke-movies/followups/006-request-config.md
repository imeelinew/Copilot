# 追问：为什么 `baseURL` 和超时时间写在请求文件里？

## 核心回答

把 `baseURL` 和默认超时集中在请求实例里，主要是避免每个 API 重复填写，也方便统一修改。当前项目设置的是豆瓣移动端地址和 5 秒超时，这对小项目比较直观。不过地址现在是硬编码，开发、测试和生产环境不方便切换。正式项目可以通过环境配置管理不同服务地址，但真正的服务端密钥不能因为使用环境变量就注入前端产物，因为客户端环境本身并不可信。

## 回答要点

- 把 baseURL 和默认超时集中在请求实例里，主要是避免每个 API 重复填写，也方便统一修改。
- 当前项目设置的是豆瓣移动端地址和 5 秒超时，这对小项目比较直观。
- 不过地址现在是硬编码，开发、测试和生产环境不方便切换。
- 正式项目可以通过环境配置管理不同服务地址，但真正的服务端密钥不能因为使用环境变量就注入前端产物，因为客户端环境本身并不可信。
