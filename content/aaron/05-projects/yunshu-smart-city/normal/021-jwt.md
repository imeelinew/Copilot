# 前端解析 JWT，为什么不校验签名？

## 核心回答

前端解析 `exp` 只是为了安排刷新和控制页面，不是在证明 Token 可信。签名校验需要可信密钥或服务端能力；即使前端能解析出角色和过期时间，用户也可以篡改浏览器状态，所以接口端必须独立验证签名、过期时间和权限。当前解析失败会把 Token 视为过期，这是一种保守处理。

## 回答要点

- 前端解析 exp 只是为了安排刷新和控制页面，不是在证明 Token 可信。
- 签名校验需要可信密钥或服务端能力；
- 即使前端能解析出角色和过期时间，用户也可以篡改浏览器状态，所以接口端必须独立验证签名、过期时间和权限。
- 当前解析失败会把 Token 视为过期，这是一种保守处理。
