# 多个请求同时 401 会刷新几次？刷新途中退出会不会又自动登录？

## 核心回答

同一页面里，如果多个 401 在刷新进行期间到达，它们会共享同一个刷新 Promise，所以这一批重叠请求只发起一次刷新，这个模式叫 single flight。刷新完成后 Promise 被释放，后续真正的新一轮仍可以再次刷新。为防止刷新途中退出后又被旧响应登录，代码会记住发起刷新时的 Token；响应回来后再和 Redux 当前 Token 比较，发现用户已经退出或切换账号就丢弃结果。它的边界是 single flight 只在当前标签页的 JavaScript 上下文生效，多个标签页之间没有共享锁；很晚才到达的旧 401 也可能在上一轮结束后触发新一轮。

## 回答要点

- 同一页面里，如果多个 401 在刷新进行期间到达，它们会共享同一个刷新 Promise，所以这一批重叠请求只发起一次刷新，这个模式叫 single flight。
- 刷新完成后 Promise 被释放，后续真正的新一轮仍可以再次刷新。
- 为防止刷新途中退出后又被旧响应登录，代码会记住发起刷新时的 Token；
- 响应回来后再和 Redux 当前 Token 比较，发现用户已经退出或切换账号就丢弃结果。
