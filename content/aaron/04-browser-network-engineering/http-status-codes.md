# 常见的 HTTP 状态码有哪些？

## 核心回答

按类记就行：2xx 成功，200、201、204 常见；3xx 重定向，301 永久、302 临时、304 是缓存命中；4xx 是客户端的问题，400 参数错、401 没登录、403 没权限、404 不存在、409 冲突、429 请求太频繁；5xx 是服务端的问题，500 内部错误，502 和 504 都是网关后面的服务出事了。

单说几个我真实处理过的。401 和 403 不一样：401 是没登录或登录过期，我的响应拦截器捕获后清掉本地会话跳登录页；403 是登录了但没权限，不该踢去登录页，应该提示无权访问，这俩混着处理是常见错误。409 在工单系统里有真用途：状态更新拿 version 做乐观锁，两个人同时操作同一张工单，后到的更新匹配不上 version，后端回 409，前端提示"工单已被处理，请刷新"，避免把别人的改动覆盖掉。

## 展开回答

301 和 302 的区别在浏览器和搜索引擎会不会记住新地址：域名迁移用 301，以后直接访问新地址；活动跳转这类临时逻辑用 302。502 和 504 都说明问题不在前端，502 是上游给了无效响应，504 是等上游超时了，这时候我能做的就是拿着请求信息去找后端。

这题我觉得重点是别背成清单。面试官想听的是你在什么场景下处理过哪个状态码，把 401、403、409 这几个讲出故事来，比列全 60 个码有用。
