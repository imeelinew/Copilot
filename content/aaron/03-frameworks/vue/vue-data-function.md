# 组件里的 data 为什么必须是一个函数？

## 核心回答

因为组件会被复用多次。data 写成函数，每创建一个组件实例就调用一次，返回一份全新的数据，各实例互不影响。写成对象的话，所有实例共享的是同一个对象引用，一个实例改了数据，其他实例全跟着变，这就是数据污染。

说白了就是个隔离问题，函数每次调用都产生新对象，对象字面量从头到尾就一份。

## 展开回答

根实例 new Vue 时可以直接写对象，因为它全局就一份，不存在复用冲突。Vue3 的组合式 API 里这个问题同样存在，setup 每次执行返回一套新的状态，机制上是等价的。

顺带一个相关的好习惯：props 也不要在子组件里直接改，数据是父组件的，要改就 emit 回去或者本地拷贝一份。
