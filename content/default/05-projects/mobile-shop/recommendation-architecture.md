# 轻购的智能导购怎样从用户描述得到推荐？

## 核心回答

轻购先让模型把自然语言解析成品类、预算、需求属性和排除条件，再由后端用商品库数据做筛选和排序。`rankProducts` 会综合品类、预算、属性、标签、卖点和商品名证据，并做商品族多样性处理，最后取前五个；模型解析失败就走 `fallbackIntent` 的规则解析。这样推荐依据仍然来自可检查的商品数据，不是让模型凭空编商品。

## 追问：AI 返回 JSON 不合法怎么办？

先限制 prompt 长度和可接受字段，再把模型返回当作不可信输入解析，字段缺失、预算异常或品类不在白名单时走规则兜底或返回可理解的空结果。排序函数还要对最终字段做类型和范围校验。当前固定场景评估能覆盖品类、预算和需求覆盖，但它不是线上用户满意度的证明，我会把这个边界说清楚。

## 追问：为什么要做商品族多样性？

同一商品的不同颜色或 SKU 可能会因为属性命中分数很高，把前五名占满，用户反而看不到其他选择。排序时按商品族做轻量去重，再保留有代表性的 SKU，能在匹配度和选择面之间取平衡。预算内没有结果时可以逐步放宽次要条件，同时把放宽原因告诉用户。
