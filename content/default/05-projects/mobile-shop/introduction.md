# 介绍一下轻购项目

## 核心回答

轻购是我做的一个移动端电商项目，前端主要用 Vue 3、TypeScript 和 Vant。用户可以在里面浏览商品、搜索、加购物车，再选地址、提交订单，查看订单状态。支付这部分目前是模拟流程。

前端的页面和交互都是我来做的，现在也有配套的 Node.js 后端。我觉得比较值得讲的是轻购 AI，也就是智能导购。用户可以直接说“800 元以内，想买通勤用的降噪耳机”，系统就会从商城里帮他挑商品，并展示匹配情况。点开以后，就能接着走原来的购买流程。

## 追问：智能导购具体怎么实现？

先让 AI 从用户的话里提取预算、品类、想要的功能和排除条件，再交给后端筛选商品。推荐用的是商品库里的数据，页面会展示商品卡片，以及哪些要求匹配上了。用户点卡片就能进详情页。

## 追问：你具体负责哪些部分？

前端的页面、路由、请求封装和购物流程是我来做的。智能导购的前端负责输入需求、等待提示、推荐展示和详情跳转；后端用 Node.js、Fastify 和 PostgreSQL，处理模型调用、需求解析和商品筛选。

## 追问：除了 AI，还有什么技术难点？

搜索联想里，我处理了连续输入时的防抖、取消旧请求和结果乱序。购物车里，要让勾选、数量和总价对得上；同一件商品正在修改数量时，会先禁用加减按钮，等请求结束再恢复。

## 追问：支付是真的接了支付平台吗？

目前是模拟支付。用户确认以后，后端更新订单状态，主要用来把下单到订单管理的流程跑通。真正接支付平台，还需要处理支付回调、验签和重复通知这些事情，这部分当前没有接入。
