# 购物车的嵌套数据和全选联动是怎么实现的？

## 核心回答

购物车接口返回的数据有好几层，先是店铺，再是店铺下面的分组，最后才是商品。我保留这个结构用来展示，同时用 computed 把里面的商品整理成一个列表，这样判断选中了哪些商品就方便一些。

每件商品都有一个选中状态，全选状态也是用 computed 算的：列表不为空，而且每件商品都选中了，全选框才会勾上。点全选的时候，就把每件商品的选中状态一起改掉。这里整理出来的列表里还是原来的商品对象，所以修改以后，页面也会跟着更新。

金额这块，我会把选中商品的购物车 ID 传给后端，让接口返回总价。勾选变化时重新请求，修改数量成功后也重新请求；没有选中商品就直接显示零。

## 展开回答

修改数量时，我用一个 Set 记录哪些商品正在提交请求。某件商品还没改完，就暂时禁用它的加减按钮，等请求结束再恢复，避免同一件商品连续发出好几次修改。接口成功后才更新页面上的数量。

当前做了商品勾选和全选，还没有做半选样式。如果要加，可以根据“至少选中一件，但没有全部选中”来判断。删除商品后，我会重新加载购物车；按现在的处理，选中状态也会重新置为未选中。
