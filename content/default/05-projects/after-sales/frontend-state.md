# 智服工单前端的 Vue2 和 Vuex 状态怎么避免混乱？

## 核心回答

全局身份、角色和跨页面筛选适合放 Vuex，表单草稿、弹窗和单页 loading 留在组件内；列表查询参数要和响应状态成对管理。Axios 统一处理 401、错误提示和登录跳转，组件销毁时清理定时器和未完成请求，避免返回旧页面后还在改状态。请求成功、失败、空数据和重试要有明确状态，不能用一个 `loading` 覆盖所有场景。

## 追问：为什么不把所有数据都放 Vuex？

全局状态越多，更新来源越难追踪，也会把一次性表单和缓存数据的生命周期拉得过长。能由 URL 重建的筛选放 URL，页面私有的输入留在组件里，真正跨页面共享的身份和权限才进入 Vuex。这样刷新、返回和登出时更容易判断哪些数据该清空。

## 追问：401 时怎样避免重复跳转？

请求层做一次性的登出动作，清 token、清用户状态并记录当前路径；后续 401 只复用这个结果，不重复 push 登录路由。登录页本身要在白名单里，否则会形成循环。恢复后再验证 redirect 是站内路径，并重新加载需要权限的数据。
