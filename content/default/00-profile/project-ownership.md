# 项目都是你一个人做的吗？后端是谁写的？

## 核心回答

这几个是个人项目，前端的页面、路由、接口对接和交互主要都是我来做，开发过程中也会用 AI 辅助。

轻购现在有配套的后端，用 Node.js、Fastify 和 PostgreSQL，提供登录、商品、购物车和订单这些接口。智能导购也有一部分逻辑在后端：调用模型理解需求，再根据商品库里的数据做筛选和排序。前端负责输入需求、展示推荐结果，以及接到商品详情和购买流程。

智服工单也有 Node.js 服务端，处理工单流转相关的业务。城市视图的重点在前端，主要是页面交互和数据可视化。

## 追问：轻购的前后端分别负责什么？

前端收集选购需求，展示推荐和匹配信息，再接到商品详情。后端调用模型提取条件，查询商品并筛选排序。下单时也是前端提交商品和地址参数，后端重新查价计算金额，不能让浏览器自己决定最终价格。

## 追问：AI 辅助写的部分，你怎么确认自己理解？

我会顺着一次操作去看数据怎么走，比如用户提交选购需求以后，先调用哪个接口，模型返回什么，筛选函数怎么用这些条件，最后页面显示什么。看不明白的地方先理清楚，再检查异常情况，不能只看正常页面能显示。

## 追问：个人项目和团队协作有什么区别？

个人项目的接口和页面可以一起改，沟通成本比较小，确实不能等同于公司里的多人协作。和后端联调时，我会先确认字段含义、错误返回和谁负责哪部分校验，遇到问题提供请求参数和返回结果，方便一起定位。
