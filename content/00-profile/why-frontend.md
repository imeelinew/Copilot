# 为什么选择前端方向？

## 30 秒回答

起点是大一加入英语协会的开发宣传部，第一次把自己做的页面真正给别人用，那种直接的正反馈让我确定了方向；后来参加校内 Web 前端设计大赛拿了三等奖，兴趣就变成了规划。理性层面我选前端有两个原因：一是它离用户最近，改一行代码马上能看到效果，适合快速建立完整的产品认知；二是它需要持续学习，而我有长期自学的习惯，GitHub 和博客都能证明。金融学院的专业背景没有成为障碍，核心课程体系是一致的，工程实践我用项目补上了。

## 标准回答

我可以拆成"怎么开始"和"为什么坚持"两部分。

怎么开始：大一进英语协会负责宣传，需要做活动页面，我从零开始学 HTML、CSS 和 JavaScript，做的页面马上就有老师和同学使用，这种即时反馈对建立信心非常重要。2024 年我拿了校内 Web 前端设计大赛三等奖，2025 年又参加了校园人工智能应用创新大赛，逐渐把兴趣变成了明确的职业方向。

为什么坚持：第一，前端的变化快，逼迫我保持学习状态，我享受这种节奏——近一年 GitHub 提交近千次，还通过博客把学到的东西写出来，写不清楚的知识点我会回头重新学。第二，前端处在产品和技术的交界处，我除了实现页面还会主动关注体验，比如轻购的搜索联想我会考虑请求失败后的降级，这让我觉得工作有产品价值。

至于学校背景，我更愿意把它看成差异化而不是短板：课程体系保证了计算机基础，同时金融场景让我对数据展示和业务规则更敏感，城市视图和工单系统这类数据密集型项目我做起来很顺。

## 回答要点

- 用具体事件（协会、比赛）说明兴趣的来源，不要说"从小热爱"。
- 把自学能力作为核心卖点，配合 GitHub 和博客证据。
- 主动回应学校背景，转化为优势。
