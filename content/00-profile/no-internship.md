# 没有实习经历，你怎么适应团队协作？

## 30 秒回答

我确实还没有正式实习经历，这也是我这次求职最想补上的一环。但我没有等到实习才开始准备协作：我的项目一直按工程规范做，分支开发、规范提交、部署上线；遇到问题我会先查官方文档和源码，而不是只搜答案；在校内担任英语协会开发宣传部负责人时，也和不同部门的同学协作完成过活动页。我相信自学的工程习惯可以迁移，缺的是真实团队节奏，而这正是我希望通过实习补齐的。

## 标准回答

我从三个方面回答这个问题。

第一是工程习惯。我的三个项目都保持连续的小步提交，GitHub 上近一年的提交记录可以看到迭代过程；代码按模块拆分，接口统一封装，部署上线和回滚都是自己操作。这些习惯在团队里是通用的，我需要调整的只是具体规范，而不是从零建立意识。

第二是协作沟通。在英语协会做开发宣传部负责人时，我要对接活动需求、协调页面和物料的时间，学会了确认需求、同步进度、及时暴露风险这些基本动作。技术协作的本质是一样的：让信息透明，让别人可以信任你的交付。

第三是开放心态。我没有在真实团队里被 review 过，所以我格外期待 code review，也做好了被大量指出问题的准备。我的学习方式一直是先模仿规范、再理解原因，这和进入团队的要求是一致的。

## 回答要点

- 不回避"没有实习"，把话题转向已具备的工程习惯。
- 用 GitHub 提交记录和校内经历做证据，不说空话。
- 把"缺团队节奏"转化为求职动机。

## 面试官可能追问

- 如果团队的规范和你的习惯冲突，你听谁的？
- code review 被连续打回怎么处理？
- 你觉得实习生最重要的素质是什么？
