# 没有实习经历，你怎么适应团队协作？

## 核心回答

确实没有正式实习过，这也是我这次求职最想补上的一块。但我没有等到实习那天才开始准备协作。我的项目一直是按工程规范做的：开分支、小步提交、写清楚提交信息、部署上线，GitHub 上近一年的提交记录是连续的，这个做不了假。另外我在学校英语协会当过开发宣传部的负责人，做活动页面要跟不同部门的人对需求、对时间，基本的沟通和协作我是经历过的。

所以我觉得自己缺的不是协作的意识，是真实团队的节奏和规范。这个只能进团队学，也正是我来找实习最主要的原因。

## 展开回答

我给自己的预期是，实习前期被 review 得越狠越好。写代码的习惯我已经有了，但命名、分层、抽象这些是不是符合团队口味，只有真实项目才能校准。还有接手别人留下的代码、在别人的模块上改东西，这些我确实没经历过，心里有数，来了会多看多问。

## 面试官可能追问

- 团队的规范和你的习惯冲突，你听谁的？
- code review 被连续打回怎么处理？
- 你觉得实习生最重要的素质是什么？
