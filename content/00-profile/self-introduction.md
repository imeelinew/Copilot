# 3 分钟自我介绍

## 核心回答

面试官您好，我叫牛颢然，是哈尔滨金融学院计算机科学与技术专业的 2027 届本科生，我今天应聘的是 Web 前端开发岗位。

技术方面，我主要使用 JavaScript 和 TypeScript 进行开发，熟悉 Vue 2、Vue 3 和 React 技术栈，能够完成组件化开发、路由与状态管理、Axios 请求封装、Token 鉴权以及前端工程化配置。我也使用过 ECharts、高德地图和 React Three Fiber 进行数据可视化开发。

项目方面，我做过三个前端项目。

第一个是基于 Vue 3 和 TypeScript 的移动端电商平台“轻购”。里面比较有特点的是智能导购，用户直接说预算和选购要求，系统就会从商城里挑选商品，并展示匹配情况。

第二个是基于 React 和 TypeScript 的城市数据可视化平台“城市视图”，主要面向城市运营人员和数据分析人员。

第三个是基于 Vue 2 的企业售后工单管理系统“智服工单”，面向客服、维修人员和售后管理员。

在校期间，我曾担任英语协会开发宣传部负责人，获得过校内 Web 前端设计大赛三等奖和校园人工智能应用创新大赛三等奖，并通过了大学英语六级，能流畅的阅读英文文档。

我对前端开发有比较浓厚的兴趣，遇到问题时愿意主动分析和反复验证。平时我有维护个人网站和撰写个人博客的习惯，也会使用 Codex、Claude Code 和 Cursor 等 AI 工具辅助开发，提高学习和解决问题的效率。

以上是我的个人情况，谢谢。

## 追问：三个项目里，你最想展开讲哪个？

我比较想讲轻购的智能导购。用户直接描述预算和选购要求，AI 提取条件，后端再从商品库里筛选，前端展示推荐和匹配情况。这个功能涉及前后端配合，也需要考虑结果有没有依据、接口失败怎么处理。

## 追问：React 项目里有什么具体实践？

城市视图里做了仪表盘和图表配置。图表容器用 ResizeObserver 监听尺寸变化，数据变化用 setOption 更新，卸载时清理实例。登录用户和主题放在 Redux Toolkit，页面自己的表单和预览状态保留在组件里。

## 追问：Vue 2 项目重点做了什么？

智服工单主要是售后处理流程。我按工单状态和用户角色控制页面操作，服务端再校验是否合法，并用事务保存状态和处理记录。还做了按问题类型计算处理时限、展示超时工单这些功能。
