# 项目都是你一个人做的吗？后端是谁写的？

## 30 秒回答

三个项目的前端都是我独立完成的，包括页面、路由、状态管理、请求封装和构建部署。后端方面，智服工单配套的服务端是我用 Node 写的，工单状态流转那些接口我自己定义和实现过；轻购接的是现成的电商接口，AI 能力走我自己搭的转发服务。所以每个项目的接口结构、字段含义和数据流我都能讲清楚，不是只对着设计稿画页面。

## 标准回答

我是把个人项目当成"完整产品"来练的，所以不希望只停留在前端页面。以智服工单为例，服务端也是我写的：工单从待分配到完成的合法流转、version 乐观锁防并发，这些规则都是我在服务端实现的，前端只是消费方。这让我对接口的理解不是"调通就行"，而是知道后端为什么这样设计、哪些校验前端做不了。

另外两个项目里，轻购使用现成的电商接口练习真实数据流，AI 部分我自己做了服务端转发来保护密钥；城市视图前端由我独立完成，重点放在状态组织、可视化和权限这些前端能力上。

我也清楚个人项目和企业协作有差距，所以我一直在用工程化的方式弥补：分支开发、规范提交、部署上线、给自己写 README 和复盘。我理解的真实协作是接需求、对接口、review 代码，这些我在项目里都尽量按团队方式演练。

## 回答要点

- 先明确"前端独立完成"，再说清后端的来源，不要含糊。
- 用智服工单的服务端证明你不只是会写页面。
- 主动承认个人项目与团队协作的差距，并给出弥补方式。

## 面试官可能追问

- 接口文档是怎么定的？前后端联调怎么做的？
- 如果接口是别人写的，你怎么快速理解并接入？
- 三个项目加起来时间不长，深度能保证吗？
