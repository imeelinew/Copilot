# 项目都是你一个人做的吗？后端是谁写的？

## 核心回答

前端全是我一个人做的，页面、路由、状态管理、请求封装、打包部署，都是自己来。后端每个项目情况不一样：智服工单的服务端是我自己用 Node 写的，因为工单流转这种业务光写前端我总觉得不踏实，状态校验、并发控制这些自己在服务端做一遍，才知道前端到底该干什么、不该干什么。轻购用的是现成的电商接口，AI 那部分自己搭了个转发服务，主要是为了不让密钥暴露在浏览器里。城市视图重心在前端，接口就是正常的数据接口。

所以项目里接口长什么样、字段是什么意思、数据怎么流动的，我都能说清楚，不是照着设计稿拼页面那种。

## 展开回答

个人项目和公司里的多人协作确实有差距，这个我不回避。我能做的是尽量按团队的方式要求自己：开分支、规范提交、部署上线，都按真实项目走。而且因为前后端都碰过，真到公司里和后端同事对接口，我知道对方需要我提供什么，也明白哪些校验前端做了也白做、必须后端兜底，沟通起来会省很多事。

## 面试官可能追问

- 接口文档怎么定的？联调流程是怎么走的？
- 接口是别人写的，你怎么快速理解并接入？
- 三个项目加起来时间不长，深度能保证吗？
