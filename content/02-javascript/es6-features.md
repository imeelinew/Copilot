# ES6+ 有哪些常用新特性？项目里用过哪些？

## 30 秒回答

按使用频率说：语法层面有 let/const、箭头函数、模板字符串、解构赋值、展开运算符、默认参数和 class；异步层面有 Promise 和 async/await；数据结构有 Map 和 Set；较新的还有可选链、空值合并和 ES 模块。项目里每天都在用的组合是：解构接口数据、展开运算符做不可变更新、async/await 写异步流程、可选链安全地访问嵌套字段。

## 标准回答

我不想罗列清单，而是按项目里的真实用法说。

处理数据时，解构和展开运算符用得最多。接口返回的对象用解构直接取字段；购物车里修改某个商品的数量，用 map 生成新数组、展开运算符替换对应项，保持数据更新是"创建新结构"而不是原地修改，这在 React 里是硬要求，在 Vue 里我也保持同样习惯。

异步方面，从 Promise 到 async/await，我的习惯是用 async/await 组织主流程，配合 try/catch 处理异常；需要并行的场景用 Promise.all，需要容忍失败的场景用 Promise.allSettled，比如仪表盘多个独立数据源并行加载。

防御性访问用可选链和空值合并，比如读取可能缺失的嵌套配置 config?.theme ?? 'light'，比层层判断简洁且不容易漏。搜索联想的缓存我用 Map 实现，用它的插入顺序做容量淘汰，比普通对象语义更清晰。

模块层面，ESM 让构建工具可以做 tree shaking，Vite 打包产物更小；箭头函数除了语法简洁，词法 this 也避免了回调里 bind 的样板代码。

## 回答要点

- 按"数据处理、异步、防御访问、模块"分组讲，每组带项目实例。
- 展开运算符要提到不可变更新的意义。
- 用 Map 做搜索缓存是真实的细节，可以主动抛出来。
