# 介绍一下轻购项目

## 核心回答

轻购是我做的一个移动端电商项目，前端主要用 Vue 3、TypeScript 和 Vant。用户可以在里面浏览、搜索商品，加购物车，再选地址、提交订单，查看后续的订单状态。支付这部分目前做的是模拟流程。

前端的页面和交互都是我来做的，包括路由、接口对接，还有购物车和下单这些流程。现在项目也有配套的后端，用的是 Node.js、Fastify 和 PostgreSQL。

我觉得比较值得讲的是里面的轻购 AI，也就是智能导购。用户可以直接说自己的需求，比如“800 元以内，想买通勤用的降噪耳机”，系统就会从商城里帮他挑商品，并告诉他哪些要求匹配上了。点开推荐商品以后，就能接着走原来的购买流程。

除了这个功能，我也处理了搜索时连续输入的请求问题，以及购物车勾选、改数量和金额更新这些交互细节。
